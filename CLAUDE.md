# TrueChan — instrucciones para el asistente

Estoy aprendiendo a programar con este proyecto (un imageboard anónimo).
Uso IA para avanzar más rápido, pero quiero entender todo lo que se escribe.

## Cómo quiero que trabajes
- Antes de escribir código, explícame en español qué vas a hacer y por qué.
- Explica cada parte del código con comentarios claros y sencillos.
- Prioriza HTML semántico (header, main, section, article), no puros <div>.
- No instales paquetes ni ejecutes comandos destructivos sin avisarme antes y explicar qué hacen.
- Si ves un riesgo de seguridad, dímelo (este proyecto es un imageboard anónimo).
- Después de cada cambio, dime qué revisar y qué concepto acabo de usar.

## Stack
- Fase actual: HTML, CSS y JavaScript puros (sin frameworks todavía).
- Más adelante: React con Vite, y Supabase como backend.
- Tema visual: imageboard clásico, fondo claro con acentos morados.
